# ISO/IEC 27001:2022 Compliance Audit — Orcanos QMS

Source: `compliance-audit` skill run, 2026-09-15 (code, Supabase, static pentest connectors; org attestation from the user). Previous run: 2026-07-29. This file tracks status in place — update in place on re-run, don't duplicate rows; each control's `history` (in `compliance/ledger.json`) keeps the trail.

**Scope note:** this audits Orcanos QMS (this repo/tool) only. Orcanos itself (the underlying data platform, and this system's hosting/data subprocessor) already holds ISO 27001 certification — its own infrastructure and ISMS are not re-audited here; that certification is used as evidence for the physical-security controls (A.7.x) this system inherits from it.
